# 選股小幫手

輸入台股代號，判斷現在是否符合「金包銀」起漲型態，並列出出場警示。僅供參考，不構成投資建議。

## 檔案

- `app.py`：網頁介面（Streamlit），分「個股分析」「我的收藏」「選股掃描」三頁
- `model.py`：金包銀判斷邏輯，所有門檻都在最上方的 `PARAMS`
- `data.py`：股票清單（證交所、櫃買中心 OpenAPI）與日線資料（Yahoo Finance）
- `requirements.txt`：需要的套件

## 部署成網址（一次性，約 10 分鐘）

1. 到 https://github.com 註冊或登入，按右上角「+」→「New repository」，名稱例如 `jinbaoyin`，選 Public，建立。
2. 在新 repo 頁面按「uploading an existing file」，把 `app.py`、`model.py`、`data.py`、`requirements.txt` 四個檔案拖進去，按「Commit changes」。
3. 到 https://share.streamlit.io 用 GitHub 帳號登入，按「Create app」→「Deploy a public app from GitHub」。
4. Repository 選剛剛的 repo，Branch 填 `main`，Main file path 填 `app.py`，可在 App URL 自訂網址（例如 `jinbaoyin-xxx`），按「Deploy」。
5. 等一兩分鐘出現頁面後，把網址傳給客戶，請她加到手機主畫面或瀏覽器書籤。

App 一段時間沒人用會休眠，打開時若看到「Yes, get this app back up」按一下，等約 30 秒即可。

## 功能說明

- **個股分析**：可輸入代號或中文名稱（例如「台積電」），按「⭐ 加入收藏」存起來。
- **我的收藏**：一鍵檢查全部收藏的股票，表格列出判斷結果，點選可看詳細分析。收藏存在該裝置的瀏覽器裡，換手機或電腦要重新加；清除瀏覽器資料也會一起清掉。
- **選股掃描**：從成交量前 100 名、前 300 名或全部上市櫃普通股中，找出五項條件全符合或剛突破的股票。前 100 名約數十秒，全部約需數分鐘；結果會暫存 6 小時，同一天再掃會很快。若證交所 OpenAPI 連不上，會改用內建的 60 檔權值股清單。

## 在自己電腦上跑

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 判斷規則（日線）

| 條件 | 量化定義 |
|---|---|
| 先跌後止跌 | 近 250 日從高點回落 ≥ 15%，且近 20 日低點不低於前 40 日低點 |
| 站上生命線 | 收盤 > 60MA |
| 60MA 走平或上彎 | 60MA 與 10 天前相比跌幅 ≤ 0.5% |
| 長均線壓頂 | 120MA 或 240MA 高於 60MA |
| 盤整震盪 | 近 20 日最高 / 最低 − 1 ≤ 15% |

結果：

- 🟢 金包銀成形：五項全過，且收盤仍在上方長均線之下
- 🟡 剛突破：5 天內收盤突破 120MA/240MA 中較高者，且有一天成交量 ≥ 20 日均量 1.5 倍，距 60MA 乖離 ≤ 10%
- ⚪ 已多頭排列或乖離偏大：已發動，不追高
- 🔴 不符合

出場警示：近 5 天高檔（近 60 日高點 5% 內）爆量（≥ 2 倍均量）黑K、之後 3 天以上未創高、跌破 5MA 且 5MA 下彎、當日跌破 60MA。

未納入：籌碼、基本面、消息面、多週期（週線/分K）比對、產業形態對比。
